Internationalization
====================

.. toctree::
   :maxdepth: 2
   
.. highlight:: none

GUI translations are done via the python internationalization framework.

In the source code, all labels are written in english.

In the translations folder, for each language the translation files are saved::

  src                   -> the project sources
  |- translations
     |- de
     |- en


To edit and update the translation files, PoEdit https://poedit.net/ is used.
